What Worked Well?

Speed

Full-stack MVP — 3 services, 8 tools, 6 widgets — built in hackathon timeframe.

Architecture Quality

AI suggested ActionCable streaming with sequence-numbered deltas for ordering guarantees.

.md Files as Context

Leveraged .md files across development so each new Claude session picks up context right away — no ramp-up time.

System Prompt Iteration

AI helped craft the strict step-by-step flow with WAIT / IMMEDIATELY semantics.

04

What Didn't Work (or Was Surprising)

Over-Engineering

GSD is a massive plugin, but planning and executing with it took too long. AI occasionally wanted to build abstractions for one-off things — had to keep pulling it back to simplicity.

WebSocket Ordering

AI's first approach didn't handle ActionCable's async adapter. Needed human debugging + AI iteration to solve.

System Prompt Iteration

Many iterations to prevent the agent from skipping steps or combining tool calls incorrectly.

Human Judgment Still Critical

UX decisions, flow design, what "feels right" in a phone conversation — humans drive the product vision.

05

What We'd Do Differently

  • Less GSD, more doing — the plugin is powerful but planning overhead ate into build time. Ship first, polish later.
  • Give EVEN MORE context to the backend POC — we thought in human terms, not in AI terms. The AI needs explicit, structured context to perform.
  • Start with the system prompt FIRST — it's the product spec. Everything else flows from it.
  • Keep AI context small and focused — leverage /clear and /compact commands to reset context between features.

Key Takeaway

AI-first approach + enough context = can build anything you'd like.
