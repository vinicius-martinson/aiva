   - Export `useTranscript(isListening: boolean, onChunk: (text: string) => void, onComplete: () => void)`:
     - `chunkIndexRef = useRef(0)` — tracks which transcript chunk to inject next
     - `timeoutRef = useRef<number | null>(null)` — holds setTimeout ID for cleanup
     - `useEffect` watching `isListening`:
       - If `!isListening`: reset `chunkIndexRef.current = 0`, clear any pending timeout, return
       - If `isListening`: call `scheduleNext()` function
     - `scheduleNext()` inner function:
       - Calculate random delay: `Math.floor(Math.random() * 4000) + 8000` (8-12 seconds)
       - `window.setTimeout` at that delay:
         - Get `chunk = TRANSCRIPT_CHUNKS[chunkIndexRef.current]`
         - If chunk exists: call `onChunk(chunk)`, increment `chunkIndexRef.current`
         - If `chunkIndexRef.current >= 2`: call `onComplete()` (triggers CLASSIFYING)
         - Else: call `scheduleNext()` recursively for next chunk
     - CRITICAL: Return cleanup function from useEffect that clears `timeoutRef.current`
     - Dependencies: `[isListening, onChunk, onComplete]`
